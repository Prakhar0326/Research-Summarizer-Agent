# Quick Start Guide - HuggingFace LLM Integration

## 🚀 Quick Setup (5 minutes)

### Step 1: Get HuggingFace API Token
```bash
# 1. Go to: https://huggingface.co/settings/tokens
# 2. Click "New token"
# 3. Set name: "ResearchSummarizer"
# 4. Select "Read" access
# 5. Copy the token
```

### Step 2: Set Environment Variable
**Windows (PowerShell):**
```powershell
$env:HUGGINGFACE_API_KEY="hf_xxxxxxxxxxxxxxxxxxxxxxxxxx"
```

**Windows (Command Prompt):**
```cmd
set HUGGINGFACE_API_KEY=hf_xxxxxxxxxxxxxxxxxxxxxxxxxx
```

**Linux/Mac (Bash):**
```bash
export HUGGINGFACE_API_KEY="hf_xxxxxxxxxxxxxxxxxxxxxxxxxx"
```

### Step 3: Run Application
```bash
./gradlew bootRun
```

### Step 4: Test with cURL
```bash
curl -X POST http://localhost:8080/api/research \
  -H "Content-Type: application/json" \
  -d '{"topic":"Can you tell me about fine tuning?","maxSources":5}'
```

## 🔧 Configuration

### application.properties
```properties
# HuggingFace Inference API
huggingface.api.key=${HUGGINGFACE_API_KEY:demo-key}
huggingface.model=mistralai/Mistral-7B-Instruct-v0.1
huggingface.timeout=30000
```

### Changing Model
To use a different model, update `huggingface.model`:

**Better Quality (Slower):**
```properties
huggingface.model=meta-llama/Llama-2-70b-chat-hf
```

**Faster (Lower Quality):**
```properties
huggingface.model=HuggingFaceH4/zephyr-7b-beta
```

## ⚡ Performance Tips

### Optimize for Speed
- Use smaller model: `HuggingFaceH4/zephyr-7b-beta` (3B params)
- Reduce `maxSources` to 1-2
- Use web search instead of MCP

### Optimize for Quality
- Use larger model: `meta-llama/Llama-2-70b-chat-hf` (70B params)
- Increase `maxSources` to 5-10
- Use MCP for technical queries

### Handle Rate Limits
- Free tier: ~30 requests/minute
- Add delays between requests
- Consider HuggingFace Inference Endpoints for production

## 🐛 Troubleshooting

### Problem: "API key not configured"
```
[WARN] HuggingFace API key not configured, returning empty response
```
**Solution:**
```bash
echo $HUGGINGFACE_API_KEY  # Verify key is set
export HUGGINGFACE_API_KEY="hf_..."  # Set if missing
./gradlew bootRun  # Restart app
```

### Problem: Empty response from LLM
```
[WARN] LLM returned empty response
```
**Causes & Solutions:**
1. **Rate limit hit** → Wait 1 minute, retry
2. **Model overloaded** → Try at different time
3. **Invalid API key** → Regenerate token at huggingface.co
4. **Network timeout** → Increase `huggingface.timeout` in config

### Problem: JSON parsing error
```
[WARN] Error parsing LLM response
```
**Solution:** System uses template fallback, extraction still works but with lower quality

### Problem: Running without API key
If you don't have HuggingFace key, the system falls back to regex-based extraction (original behavior) with reduced quality.

## 📈 Upgrade Path

### Current Setup
- **Model**: Mistral-7B-Instruct (7B params)
- **Provider**: HuggingFace Inference API (Free)
- **Cost**: Free (with rate limits)

### Production Upgrade
1. **HuggingFace Inference Endpoints**
   - Dedicated hardware
   - No rate limits
   - Cost: ~$0.10/hour for 7B model
   - More details: https://huggingface.co/inference-endpoints

2. **Local Deployment (Ollama)**
   - Download: https://ollama.ai
   - Run locally: `ollama run mistral`
   - Cost: Free (compute only)

3. **Commercial Providers**
   - OpenAI: `gpt-4-turbo` (better quality, $$$)
   - Anthropic: `claude-3-sonnet` (better reasoning, $$)
   - Groq: `mixtral-8x7b` (very fast, free)
